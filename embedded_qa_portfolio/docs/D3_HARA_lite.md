# D3. HARA-lite — BMS 위험 분석 (v0.1)

> **이 문서는 ISO 26262 Part 3의 HARA(위험 분석 및 리스크 평가) 개념을 적용한 학습용 산출물이다.
> 평가·심사·인증을 거친 결과가 아니며, S/E/C 등급과 ASIL은 공개 자료를 바탕으로 한 개인의 추정이다.**
> 근거 요건: [A11]. 하위 산출물: `requirements/safety_goals.yaml` → `requirements/swr.yaml`.

## 1. 아이템 정의

| 항목 | 내용 |
|---|---|
| 아이템 | 전기차 고전압 배터리 팩용 BMS (개념 모델: 4직렬 셀, 온도 센서 2개, 전류 센서 1개, 메인 컨택터 1개) |
| 기능 | 셀 전압·온도·전류 측정, 이상 상태 보호(컨택터 차단), 상태·고장 보고(CAN), SOC 추정, 진단(UDS) |
| 경계 | 포함: BMS 소프트웨어, 컨택터 명령 출력. 제외: VCU, 충전기, 셀 자체, 컨택터 하드웨어 |
| 외부 인터페이스 | VCU ↔ BMS CAN (컨택터 요청, 상태 보고), 진단 테스터 ↔ BMS (UDS) |
| 안전 상태 | 메인 컨택터 개방 (단, SG-05의 주행 중 비의도적 개방은 별도 위험으로 다룸) |

## 2. 운행 상황

| ID | 상황 |
|---|---|
| OS-1 | 고속도로 주행 (고출력 방전) |
| OS-2 | 시내 주행 (가감속, 회생 충전) |
| OS-3 | 주차 중 충전 (완속·급속) |
| OS-4 | 저온 환경 충전 (0 °C 미만) |
| OS-5 | 주차 (장기 방치) |

## 3. 위험 분석과 ASIL 추정

S(심각도) S0~S3, E(노출) E0~E4, C(통제 가능성) C0~C3. ASIL은 ISO 26262-3의 S/E/C 조합표를 따른다.

| ID | 고장 행동 (BMS 관점) | 운행 상황 | 위험 사건 | S | E | C | ASIL (추정) | 근거 |
|---|---|---|---|---|---|---|---|---|
| HZ-01 | 과전압 상태에서 충전 경로를 차단하지 않음 | OS-3, OS-2 | 셀 과충전 → 열폭주·화재 | S3 | E4 | C3 | D | 충전·회생은 일상적이고, 화재는 운전자가 통제할 수 없음 |
| HZ-02 | 저전압 상태에서 방전 경로를 차단하지 않음 | OS-1, OS-5 | 과방전 셀의 재충전 시 내부 단락 → 화재 | S3 | E3 | C3 | C | 과방전까지 가는 상황은 충전보다 드묾 |
| HZ-03 | 과온 상태에서 전류를 차단하지 않음 | OS-1, OS-3 | 열폭주·화재 | S3 | E3 | C3 | C | 고부하 지속이나 냉각 이상 시 발생 |
| HZ-04 | 과전류(외부 단락) 시 전류를 차단하지 않음 | OS-1 | 배선 과열·화재 | S3 | E2 | C3 | B | 외부 단락은 드문 사건 |
| HZ-05 | 고장이 없는데 주행 중 컨택터를 개방 | OS-1 | 고속 주행 중 구동력 상실 → 후방 추돌 | S2 | E4 | C2 | B | 대부분의 운전자는 관성 주행 후 갓길 정차가 가능하다고 가정 |

**저온 충전(OS-4)** 은 별도 위험으로 두지 않고 HZ-01의 원인(리튬 석출 → 내부 단락)으로 다룬다.

## 4. 안전 목표

| ID | 안전 목표 | ASIL (추정) | 안전 상태 | 고장 허용 시간 (가정) | 근거 위험 |
|---|---|---|---|---|---|
| SG-01 | 셀 과전압 또는 충전 조건 위반 시 충전 전류를 차단해야 한다 | D | 컨택터 개방 | 500 ms | HZ-01 |
| SG-02 | 셀 저전압 시 방전 전류를 차단해야 한다 | C | 컨택터 개방 | 500 ms | HZ-02 |
| SG-03 | 셀 과온 시 전류를 차단해야 한다 | C | 컨택터 개방 | 500 ms | HZ-03 |
| SG-04 | 과전류 시 전류를 차단해야 한다 | B | 컨택터 개방 | 100 ms | HZ-04 |
| SG-05 | 고장이 없을 때 주행 중 컨택터를 개방해서는 안 된다 | B | 컨택터 유지 + 경고 | — | HZ-05 |

SG-05는 SG-01~04(차단)와 충돌한다. 통신 고장처럼 "BMS가 확신할 수 없는" 상황에서는 즉시 개방하지 않고 경고 후 전류가 낮아졌을 때 개방하는 절충을 SWR-015(판정·보고)와 SWR-030(개방 조건)에서 정한다.

## 5. 이 연습에서 다루지 않은 것

- 기능 안전 개념(FSC)·기술 안전 개념(TSC)의 하드웨어 아키텍처 메트릭(SPFM, LFM, PMHF)
- ASIL 분해(decomposition)
- 확인 검토(confirmation review)와 독립성 요구
- Cybersecurity(ISO/SAE 21434) 위협 분석
